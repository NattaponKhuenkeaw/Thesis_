# Regression: RouteOffer 3 Paths + Random

อายเทสชิ้นนี้. งานแก้โค้ดเสร็จแล้ว ไม่ต้องแก้ต่อ.

## Setup

เริ่มรันจาก Lobby ตามปกติ แล้วเคลียร์ห้องไปเรื่อยๆ จนเห็น Choice UI ที่ทางออก

## Cases

### A. หลังเคลียร์ห้องแรก

- [ ] มี **3 ใบ** เสมอ ไม่ใช่ 2
- [ ] ใบ combat โชว์ difficulty / reward ที่อ่านได้

### B. เคลียร์ 3–4 ห้องติด

- [ ] ทุกครั้งยังขึ้น 3 ใบ (ยกเว้นตอนบอส)
- [ ] เลย์เอาต์ห้องซ้ำได้ แต่คลื่นมอน / ความยาก / รางวัลไม่ควรเหมือนกันเป๊ะทั้ง 3 ใบ

### C. ทาง Shop / Level / Rest

- [ ] เมื่อมีห้องปลอดภัย มันเป็น **1 ใน 3** ไม่ได้แทนที่เหลือให้เหลือใบเดียว
- [ ] อีก 2 ใบเป็น combat ที่สุ่มได้

### D. บอส

- [ ] ถึงเกตบอสแล้วยังขึ้นบอสใบเดียวได้

## Fail if

- ขึ้น 2 ใบหลังเคลียร์ห้องธรรมดา
- ห้องที่เคยเข้าแล้วทำให้ตัวเลือกเหลือไม่ครบ 3
- 3 ใบ combat เป็น Easy เหมือนกันทั้งชุดบ่อยจนเลือกไม่มีความหมาย
