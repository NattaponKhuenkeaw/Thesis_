# Regression: Enemy 1 / 2 / 3

อายเทสชิ้นนี้. งานแก้โค้ดเสร็จแล้ว

ตัว 1 แดง melee ขัดได้ / ตัว 2 melee ง้างแล้วขัดไม่ได้ / ตัว 3 ฟ้า ยิงไกล ไม่ถอย

## Setup

เริ่มรันจาก Lobby แล้วเข้า Combat ปกติ (ห้องหลังๆ มีตัว 3 ปน)

## Cases

### A. ตัว 2 (Commit melee)

- [ ] ยืน / เดิน โดนตีแล้วยังติด hitstun ตามปกติ
- [ ] พอขึ้นเครื่องหมายง้าง ตีแล้วเลือดลดแต่ **ไม่สะดุด** จนไม้จบ
- [ ] หลังไม้จบ ตีได้อีกครั้ง (ไม่ได้เกราะยืน)

### B. ตัว 1 (Interruptible melee)

- [ ] ง้างค้างอยู่ ตีแล้วโจมตีหลุด
- [ ] ไม่มี Super Armor สีส้มตอนยืน

### C. ตัว 3 (Ranged hold)

- [ ] ยิงกระสุนจากไกล ไม่ต้องเดินเข้ามาติดตัวก่อน
- [ ] ผู้เล่นเดินเข้าใกล้แล้ว **ไม่ถอย / ไม่สไตร์ฟหนี**
- [ ] ยังหันมายิงได้ตอนผู้เล่นอยู่ใกล้

### D. Mix

- [ ] ห้อง combat มีทั้งสามแบบปนได้ โดยกราฟ AI ชุดเดิม
