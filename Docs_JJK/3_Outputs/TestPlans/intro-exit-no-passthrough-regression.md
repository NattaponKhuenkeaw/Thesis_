# Regression: Intro / Exit ไม่เดินทะลุฉาก

อายเทสชิ้นนี้ก่อนส่ง. กระทบการเล่นถ้าพัง.

## Cases

### A. ทางออก — กดตีตอนเดินออก

1. เคลียร์ห้อง เดินไปทางออก
2. **กดตีค้าง** ตอนโดน trigger / ตอนตัวเดินออกฉาก
3. ต้องเดินออกแล้วเฟด ไม่โผล่ทะลุกำแพงต่อ และห้ามโจมตีค้างในห้องถัดไป

### B. ทางเข้า — กดตีตอนเดินเข้า

1. เข้าห้องใหม่
2. **กดตี / แดช / กระโดด** ตอนตัวยังวิ่งจากซ้ายเข้ามา
3. ต้องวิ่งเข้าจุดหยุดแล้วค่อยคุมได้ ห้ามเดินทะลุซ้ายออกนอกฉาก

### C. สลับห้อง 3–4 ครั้ง

- [ ] เข้า-ออกซ้ำแล้วยังไม่ทะลุ
- [ ] Choice 3 ใบยังขึ้น
- [ ] ตายแล้วกลับ Lobby เป็นตัวหลัก
- [ ] ในไบโอม 2 กลับเข้าห้อง Combat จาก Shop, Rest และ Level ทีละแบบ พอเฟดเปิด ตัวละครต้องเข้าจากทางเข้าของห้องใหม่ ไม่วิ่งลอยย้อนมาจากฝั่งขวา
