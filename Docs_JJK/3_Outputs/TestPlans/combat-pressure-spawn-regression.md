# Regression: Combat Pressure Spawn

อายเทสชิ้นนี้. งานแก้โค้ดเสร็จแล้ว

## Setup

เริ่มรันจาก Lobby แล้วเข้าห้อง combat ปกติ (เนื้อหา combat ส่วนใหญ่มาจาก RouteOffer)

## Cases

### A. ทยอยเกิด

- [ ] เข้าห้องแล้วมอน **ไม่โผล่ครบโควต้าทีเดียว**
- [ ] พร้อมกันในห้องประมาณ **3 ตัว** (ไม่เกิน cap)
- [ ] ตัวต่อไปเกิดห่างกันนิดหน่อย ไม่พรวดเดียว

### B. ตายแล้วเติม

- [ ] ฆ่า 1 ตัว → มีตัวใหม่เกิดทดแทน ถ้าห้องยังไม่หมดโควต้า
- [ ] ฆ่าจนครบโควต้าแล้วไม่เหลือตัว → ปลดทางไปห้องถัดไป

### C. จุดเกิด

- [ ] ตัวตีใกล้เกิดช่องใกล้ผู้เล่น
- [ ] ตัว 3 (ยิงไกล / สีฟ้า) เกิดช่องไกลกว่า

### D. บอส

- [ ] ห้องบอสยังเกิด Executioner ทั้งคลื่นแบบเดิม ไม่ใช้ Pressure refill
