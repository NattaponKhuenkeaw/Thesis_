# Regression: หลายห้องใน 1 เลย์เอาต์ combat

งานโค้ดเสร็จแล้ว ต้องวางห้องใน Prefab ก่อนเทสด่านหลายห้อง

เลย์เอาต์ที่ยังไม่ใส่ `CombatStageController` ต้องยังเป็น 1 ห้องแบบเดิม

## Setup

- Combat ที่ยังไม่แตะ: เข้าจาก Lobby ตามปกติ
- Combat ที่ใส่ Chambers แล้ว: Size ตามจำนวนห้องที่วาง

## Cases

### A. เลย์เอาต์เดิม (ไม่มี CombatStageController)

- [ ] เคลียร์ศัตรูแล้วขึ้นทางออก / การ์ด 3 ใบแบบเดิม
- [ ] กล้องยังล็อกกำแพงซ้าย-ขวาของห้องนั้น

### B. ด่าน 2+ ห้อง

- [ ] ห้อง 1 เคลียร์แล้วเดินไปห้อง 2 ได้ **ยังไม่ขึ้น Choice**
- [ ] เข้าห้อง 2 แล้วมีสปอว์นชุดใหม่จากจุดเกิดของห้อง 2
- [ ] ระหว่างสู้ห้อง 2 ยังเดินข้ามไปห้อง 3 ไม่ได้จนกว่าจะเคลียร์
- [ ] ระหว่างสู้ห้อง 2 เดินกลับไปห้อง 1 ได้
- [ ] กล้องไม่วาร์ปเมื่อเข้าห้องถัดไป (ขอบซ้ายไม่หดกลับ)
- [ ] เคลียร์ห้องสุดท้ายค่อยขึ้นการ์ด 3 ใบ และยังเดินย้อนห้องที่ผ่านมาได้

### C. Encounter ต่อห้อง

- [ ] ห้องลาก Encounter คนละไฟล์ได้ชนิดตัวต่างกัน
- [ ] Enemy Count = 3 ได้ประมาณ 3 ตัว จาก Encounter ของห้องนั้น
- [ ] ห้องที่ Count = 0 ไม่สปอว์น เปิดทางเดินต่อ
- [ ] บอสยังใช้ Waves ชุดล็อก ไม่ได้เป็นแค่ชนิดตัว

### D. Boss / Shop

- [ ] บอสยัง Burst ห้องเดียว ไม่ติดลำดับห้อง combat
- [ ] ร้านยังออกได้ตอนเข้า
