# Room walls + camera lock — Editor wiring

โค้ดซิงก์กำแพงกับกล้องให้แล้ว **ตำแหน่งกำแพงในเลย์เอาต์คุณวางเอง**

## บนเลย์เอาต์ห้อง (prefab)

ต้องมี `SceneBoundaryController` แล้วลาก:

1. **Entrance Wall** — BoxCollider2D ทึบ ด้านซ้าย ขอบที่หันเข้าห้อง = ด้านขวาของคอลไลเดอร์
2. **Exit Wall** — BoxCollider2D ทึบ ด้านขวา ขอบที่หันเข้าห้อง = ด้านซ้ายของคอลไลเดอร์ (กันออกจนกว่าจะเคลียร์ห้อง)
3. **Exit Trigger** — ไม่บังคับ ถ้ามี ใช้เปิด Choice UI หลังปลดล็อก

อย่าทำกำแพงเป็น Trigger ระบบจะบังคับเป็นคอลไลเดอร์ทึบตอนรัน

## พฤติกรรมตอนเล่น

- เข้าห้อง combat → กำแพงขวา + กล้องล็อกที่ขอบกำแพง
- เดินชนขอบ → ติดกำแพง และผู้เล่นอยู่ขอบจอ (confiner slowing ถูกปิดชั่วคราว)
- เคลียร์ห้อง → `RoomExitPresenter` ปลดล็อก กำแพงขยายออก กล้องตาม

ห้อง Safe (Shop / Rest / Lobby) ยังปลดล็อกทางออกตอนเข้าตามของเดิม

## ไม่ต้องแตะ

- `CameraSetUp` / `ConfinderBound` — สคริปต์ย่อความกว้าง runtime แล้วคืนค่าเมื่อออกห้อง
