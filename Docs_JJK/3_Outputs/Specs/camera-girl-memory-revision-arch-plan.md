# Camera Girl revision: implemented architecture

The user's supplied kit values and permission to improve the existing architecture authorize this implementation. Gameplay reads saved CharacterObject, ActionResolverTable, ProjectileData and RuntimeEffect recipes. `CameraGirlMemoryAuthoring` is an explicit editor menu for authoring those assets; it has no runtime initialization hook. No Camera Girl configuration block was added to the runtime potential schema.

- Potential nodes contain the eighteen upgrades. Existing potential replacement rules now compare recipe identity as well as formula identity, allowing CR/CD and separate on-hit reactions to coexist. The existing global potential ceiling supports six ranks while each character still exposes its authored nodes.
- `OnHitRecipeRuntimeEffectDefinition` provides filtered recipe applications, a shared internal cooldown and source-keyed Skill cooldown reduction. Its state belongs to the source's inventory effect, including off-field hits. Additional damage uses the existing terminal proc policy and live source stats.
- Generic recipe parameters add action sets, marked-target filters, damage delivery conversion, splash assets, stat contribution caps, movement multipliers and periodic round-robin selection. Empty options preserve existing behavior. Target-owned damage-input recipes now reach unified mitigation; Captured uses this path rather than editing enemy base stats.
- Len Focus is a ten-second source-owned periodic effect. A saved strike projectile deals 100% source DEF to one selected enemy per second. Its separate saved lens icon uses shared recipe presentation and follows the active character. Ally speed/dash recipes require the source summon to remain active. Recasting refreshes the same effect identities.
- Shadow Assist reuses the existing executor and authored Shadow Attack. The highest eligible rank rolls once; generated additional hits and the clone's own action cannot retrigger it. Rank5's 650% DEF override is a total step budget distributed over authored hit weights; earlier ranks retain their original formula. Explicit AE rewards suppress ordinary hit AE and grant once after confirmed damage.
- Mastery is a saved Skill action cloning the normal step that uses cg_attack6. Existing input/tag conditions gate it behind the ten-second follow-up. The mark filter snapshots target effects before the hit's passive applications, preventing the initial marking hit from opening that window. Passive4 converts delivery through a DamageInput recipe and awards five AE on completion.

The starting splash radius is 3 units using the shared ExplosionSplash asset. Len Focus's one-second cadence and team-wide aura were explicitly confirmed by the user. Ultimate3 is a 30-second total duration. Human playtest covers visual reach, cadence and animation feel; no merge, publication or build-setting change is included.
