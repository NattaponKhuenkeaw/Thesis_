# Route Reward Pool

Changed the Hard reward patterns to 10% Soul + 2 Artifacts, 30% Soul + 1 Artifact, 30% Soul + 1 Memory, and 30% Big Soul. Artifact patterns no longer grant Memory. Ordinary Hard Soul pays 150% of biome base; Big Soul pays 350%.

The current authored pool assigns the pure Big Soul result a 30% weight. No tests or Unity runtime verification were requested.
