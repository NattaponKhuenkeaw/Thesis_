1. ภาพรวมวงรัน

การ์ดถูกทอยตอนเคลียร์ห้อง แล้วแคชไว้ UI เปิดเมื่อผู้เล่นยืนที่ Exit ที่ปลดล็อกแล้ว เลือกใบ → จำใบนั้น → โหลดห้อง → เล่น → เคลียร์ แล้ววนใหม่

ชั้นไทป์หน้าที่
แคตตาล็อกMapSO / RoomDataห้องมีอะไรบ้าง, ชนิด, เลย์เอาต์, น้ำหนักสุ่ม
เลือกเส้นทางRoomChoiceDirectoract ของ biome + กติกา 3 ใบ
เนื้อหาการ์ดRouteOfferGeneratorความยาก + รางวัล + พาเลตศัตรู
ใบที่เลือกActiveRouteOfferจำการ์ดจนกว่าจะเคลียร์หรือเปลี่ยนห้อง
เล่นห้องRoomLayoutHost / CombatStageControllerสลับเลย์เอาต์, หลายห้องย่อยในด่าน
ความก้าวหน้าRunProgressionManagerdepth, biome index, สเกลศัตรู
เดินทางSceneTransitionManagerเฟด, สลับเลย์เอาต์หรือโหลดซีน, แจ้งออกจากห้อง

2. ระบบห้อง

RoomData คือรายการในแคตตาล็อก ไม่ใช่ฉากที่เล่นอยู่แล้ว แต่ละห้องมี RoomId, RoomKind, ZoneMode, และทางเลือกโหลด:

  • layoutPrefab + ซีน shell เดิม → สลับเลย์เอาต์ในที่ ผ่าน RoomLayoutHost.MountRoom
  • Shop / Level ใช้ซีนแยก → โหลดซีนเต็ม แม้มี host อยู่

Lobby ถูกใส่เป็น Shop แต่ IncludeInRandomOffers = false เพื่อไม่ให้การออกจากล็อบบี้ไปเผาโควต้า Shop ของ biome

ชนิดห้อง

RoomKindZoneในพูลสุ่มทำอะไร
CombatCombatZoneใช่หลายห้องย่อย + พาเลต Easy/Medium/Hard จากใบที่เลือก
EliteCombatZoneใช่เหมือน Combat แต่ความยากเอนไป Medium/Hard
ShopSafeZoneใช่ (โหนด Shop)ซื้อของ ทางออกปลดตอนเข้า
LevelSafeZoneone-shot ต่อ biomeรับ Run Global Level ครั้งเดียวต่อการเข้า
RestSafeZoneone-shot ต่อ biomeฮีลทีมครั้งเดียวต่อการเข้า
BossCombatZoneไม่สุ่มบังคับใบเดียว Boss_01 จาก EncounterSO ที่ใส่ในห้อง
RewardSafeZoneชนิดเก่านับเป็นห้องปลอดภัย ไม่ได้อยู่บน act เริ่มต้น

โหลดห้องและเคลียร์

Combat spawn อ่านความยากจาก ActiveRouteOffer แล้วเลือก Encounter_Easy / _Medium / _Hard จำนวนศัตรูต่อห้องย่อยมาจาก enemyCount บน chamber ไม่ใช่จาก RoomData.Encounter (อันนั้นเป็น fallback / บอส)

หนึ่ง RoomLayout_Combat_* = หนึ่งด่าน หลาย chamber ไม่เท่ากับหลายห้องใน MapSO

3. ระบบ RouteOffer

หลังเคลียร์ RoomExitPresenter.PrepareOffers() เรียก GenerateOffersAfterClear() ทอยใบไว้ก่อน UI ยังไม่เปิด จนกว่าผู้เล่นจะยืนใน Exit (TransitionTrigger.openRoomChoiceUi)

เลื่อน act

GenerateOffersAfterClear

ใช้หลังเคลียร์ Combat / Elite / Boss ทำเครื่องหมายห้องที่เข้าแล้ว แจ้ง RunProgressionManager สร้างการ์ดชุดถัดไป แล้วเลื่อน actIndex

ไม่เลื่อน act

GenerateLeaveOffersFromSafeRoom

ใช้ตอนออก Shop / Level / Rest เคอร์เซอร์เลื่อนไปแล้วตอนที่ใบนั้นถูกเสนอหลังเคลียร์ห้องก่อนหน้า จะไม่ยัด safe ชนิดเดิมซ้ำตอนเดินออก

กติกาใบ

กติกาพฤติกรรม
จำนวนใบทางเลือกปกติเสมอ 3 ใบ บอสเป็นใบเดียว
Safe ≤ 1ในชุดเดียวกันมี Shop หรือ Level หรือ Rest ได้แค่ชนิดเดียว
โชว์ใบ ≠ ใช้โควต้ามี Shop บนการ์ดแต่เลือก Combat แล้ว Shop ยังใช้ใน biome นั้นได้ เผาโควต้าตอนเข้าห้องจริงผ่าน NotifyLeavingRoom
Combat / Elite / Shopอยู่ในพูลซ้ำได้ ชุด 3 ใบปัจจุบันเลี่ยง RoomId ซ้ำก่อน แล้วค่อย pad Combat ถ้าเลย์เอาต์ไม่พอ
Level / RestRoomId เป็น one-shot ต่อ biome ปลดเมื่อขึ้น biome ใหม่
ความยากไม่ซ้ำการ์ด Combat reroll สูงสุด 3 ครั้ง เพื่อไม่ให้ Easy/Medium/Hard ซ้ำกันทั้งสามใบ
น้ำหนักPickWeighted ใช้ RoomData.OfferWeight ห้องที่ IncludeInRandomOffers = false ไม่ถูกสุ่ม
บอสโหนด Boss ในเทมเพลตบังคับ Boss_01 depth เป็นเพดานสำรอง ห้ามดึงบอสมาเร็วเกินไป

4. ระบบ Biome ทั้งก้อน

Biome ในโปรเจกต์นี้มีสองความหมายที่ทำงานคู่กัน

Combat ก่อนบอส = 4 จุด · depth เป็นเพดานสำรอง (roomsBeforeBoss = จำนวน Combat + 2) เพื่อไม่ให้บอสแย่งคิว Shop / Level / Rest

  • Combat — ชุด 3 ใบเป็น Combat/Elite เป็นหลัก เคลียร์แล้ว currentRoomDepth++
  • Shop / Level / Rest — ยัดห้องปลอดภัย 1 ใบในชุดนั้น ถ้ายังไม่ถูกใช้ใน biome นี้
  • Boss — บังคับ Boss_01 เทมเพลตเป็นตัวตัดสิน

actIndex เดินหลัง GenerateOffersAfterClear (เคลียร์ไฟต์) ไม่เดินตอนออกจากห้องปลอดภัย

4.2 Biome index — สเกลความยากระหว่าง biome

RunProgressionManager.currentBiomeIndex เริ่มที่ 0 เคลียร์ Combat/Elite → depth +1 เคลียร์ Boss → depth = 0 และ biome +1 สถานะศัตรูพื้นฐาน (HP / ATK / DEF) คูณ 1 + biome × 0.12 ตอนสปอว์นใน RoomWaveManager ไม่ใช่ตอนทอยการ์ด

หลังบอส

  1. เคลียร์บอส → BeginNextBiome() รีเซ็ต act, ธง Shop/Level/Rest และปลด visited ของ Level/Rest เพื่อให้รอบใหม่เสนอได้อีก
  2. pendingPostBossRest พยายามใส่ Rest ในใบถัดไป ถ้าไม่มีห้อง Rest ใน MapSO จะตกไปทอย act ปกติ
  3. biome ใหม่เล่นเทมเพลต 8 จุดเดิมอีกครั้ง แต่ศัตรูแข็งขึ้น 12%

รันใหม่ (ResetRouteState) รีเซ็ตทั้ง act, visited, depth และ biome กลับ 0
