# Main Void Area particle preview

Latest color pass: luminous cyan-blue roots, vivid blue-violet flame folds, additive floor glow and dark upper smoke, following Apricha's newer color references. Both PNGs and the GIF reflect this tuning.

Current revision follows Apricha's supplied dark-flame references: broad shaded violet flame folds, curling black smoke, soft ground pools and tiny filled embers. The former narrow outlined pieces have been replaced.

Generated by Unity's isolated preview scene, without saving changes to Test_Playground.

- `combat-scale.png`: Main idle and EnemyCore silhouettes against the field.
- `full-width.png`: the entire 45-unit field.
- `motion.gif`: 2.4 seconds of Unity particle simulation, including rising/dissolving fragments.

Recreate assets: `Tools > Project > Main Void Area > Create Particle Assets`.
Verify and recapture: `Tools > Project > Main Void Area > Verify and Capture`.

Presentation height is editable on the `VoidAreaParticleVisual` component in `Assets/Project/Resources/FieldEffects/MainVoidAreaParticles.prefab`. Width comes from the resolved projectile routine hitbox and size multiplier. The prefab uses five standard Unity ParticleSystems and procedural URP materials: ground glow, flame, smoke, soft black halo and rising flame fragments. No animated sprite sheet is used.

The capture command also writes 24 motion frames to `%TEMP%/CodexVoidAreaParticlePreview/`. `motion.gif` was assembled from those Unity frames using Pillow (100 ms per frame); particle movement and shader preview time advance explicitly while actors remain static. Runtime uses Unity's normal shader time.
