# ADR-017: Unified action catalog/input binding proposal — withdrawn

Status: **Withdrawn**, 2026-10-29. The user explicitly rejected the broader catalog/executor/cost
refactor. It was not implemented. Action Type is limited to interrupt policy and Ultimate white
hit flash; existing input routes, costs and categories remain. Dimension Slash is a zero-AE
Skill-input EX action with Ultimate interrupt classification.
