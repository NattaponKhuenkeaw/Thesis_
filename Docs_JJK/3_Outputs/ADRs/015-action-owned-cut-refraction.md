# Action-owned cut refraction

Date: 2026-10-28. Status: implementation for human feel review.

GDD: `@tag:visual-audio` calls for large supernatural hit shapes with readable silhouettes and danger zones. The user requested chromatic aberration and a wind-like wave that bends the background during cut impact. This extends the approved action presentation; ActionResolver routing is unchanged.

The existing 2D renderer has no screen capture effect, camera opaque texture or sorting-layer copy enabled. Reuse the installed URP FullScreenPassRendererFeature through a gated subclass. Its existing fetch-color path supplies the rendered scene, including transparent sprites, before postprocessing. Following the user's correction, the material warps the sampled scene in a band along the rendered cut, with localized RGB separation and blur across its edges. The original circular hit-anchor pulse is superseded. Point sampling and reference-pixel offsets preserve the pixel style. Screen-space overlay HUD renders afterward; world-space and camera-space UI already in the camera image can be distorted.

ProceduralSlashField owns the optional settings, captured facing, ribbon geometry/timing, interpolated action frame and registration lifetime. Ribbon distortion uses the exact generated primary ribbon's angle, center, length, reverse reveal and shrinking dimensions; it follows the latest visible primary ribbon when several overlap. Mask distortion uses the actual quad's center/size, mirrored screenMaskAngle and the mask shader's reveal/opening/fade equations. The band follows the revealed segment, with an accent at its moving leading edge. Begin registers; Stop/disable/destruction unregister. The pass checks live execution ownership and field-session validity before enqueuing. Pause/hitstop hold the sampled frame. The latest eligible event wins rather than accumulating strengths. Only the owning gameplay camera, or Scene View while explicitly scrubbing a preview, is eligible. No pass or color copy is enqueued outside a pulse. No global Volume is changed. Reuse URP's implementation for RenderGraph and compatibility mode instead of maintaining another custom render graph.

Enable the effect on the DimensionSlash barrage, DimensionSlashFinalCut and Execution Breakdown's final screen tear. The barrage was initially omitted; a user-reported correction adds it to the authoring filter and enables it in generated settings. Start when the rendered cut becomes visible. Starting values: 18 logic frames, band width 0.08 viewport heights, refraction 6 reference pixels, RGB separation 2 pixels, localized edge blur 1 pixel at 270 reference pixels high. These values require human feel review. Proposed manual check: the warped band should coincide with the visible diagonal through reveal, facing reversal and shrink; actor silhouette, enemy tells and HUD must remain readable. Reduce refraction/RGB/blur if silhouettes break; adjust band width if the warp extends too far from the cut. No gameplay tests or capture are run, as requested by the user.

The dedicated authoring menu installs the feature/material and changes only the optional impact fields on existing finishing events. It preserves authored angles, VFX timings, hit data, actor animation and QTE trees. No package, build, CI, physics or timestep configuration changes are needed. The Renderer2D asset gains one gated feature. Rendering cost and artistic quality remain unmeasured until the user requests validation.

Expansion to sprite cuts and Lightning Plunge: optional `VFXEntry.impactDistortion` feeds a `CutImpactVfxSource` adapter. It reads the current SpriteRenderer sprite bounds and transform at render time, follows translation/rotation/facing/scale, and stops with the pooled visual or action ownership. This approximates a sprite cut by its longest bounds axis, rather than reconstructing its curved silhouette. Animation Editor scrubs the same adapter. LightningPlungeVFX supplies current contact/ceiling endpoints and a frame relative to ground contact; its independent tail controls source lifetime. The shader pass first prefers active procedural slash events, then the latest eligible sprite/bolt source, so overlapping effects do not stack unbounded strengths.

Authoring now enables DimensionCut's primary sprite, Execution Breakdown's six burst sprites and final tear, DimensionSlash's barrage/final cut, and Lightning Plunge's profile. A mild plunge starting profile uses12 frames, band width0.04 viewport heights,4 reference pixels of refraction,0 RGB split and0 blur. DefaultVolumeProfile currently has ChromaticAberration intensity0.1, a plausible source of the user's observed lightning fringe, not visually confirmed here. The plunge opts into suppressing that effect in the active camera's evaluated runtime Volume stack. The feature restores the original value at endCameraRendering, before another camera, on recreation and on disposal; the saved global profile remains unchanged. Suppression persists while the visible bolt/tail exists even after its short refraction pulse has finished. Human feel/performance review remains pending; no gameplay tests or captures are run.
